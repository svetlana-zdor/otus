Простая N-gram модель предсказания слов (Simple LLM)
Этот проект представляет собой базовую реализацию языковой модели на Python. Модель умеет обучаться на наборе текстовых данных и предсказывать наиболее вероятное следующее слово на основе частотности пар слов (биграмм).

Особенности
Простота и легковесность: Не требует установки массивных сторонних фреймворков (используются только встроенные модули Python, такие как collections.defaultdict).

Обучение на лету: Быстрый подсчет статистики встречаемости слов при инициализации.

Наглядность: Отличный пример для понимания того, как работают базовые вероятностные языковые модели "под капотом".

Как это работает
Алгоритм основан на N-граммах (в данном случае — биграммах).

Во время обучения метод train разбивает входные предложения на отдельные слова по пробелам.

Программа составляет частотный словарь, подсчитывая, сколько раз конкретное слово B следует за словом A.

При вызове метода predict_next_word модель ищет заданное слово в своем словаре и возвращает то слово, которое следовало за ним чаще всего.
